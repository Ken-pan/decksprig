# Figma Slides ↔ Deck Studio

Build with `npm run build:figma`. In Figma Desktop, import this folder's `manifest.json` as a development plugin and open **Decksprig · Slides sync**. Keep the local editor running at http://127.0.0.1:4310/.

In Deck Studio's document menu, choose **Figma Slides sync**, choose the direction, click **Copy connection code**, and paste the code in the plugin. If clipboard access is unavailable, the code is selected for manual copying. Use the optional slide range to scope the first connection (`1–14, 20`). Blank uses the selected slides, or the whole file when none are selected. Capture supports up to 100 slides; use smaller batches for image-heavy decks that exceed the 100 MB request limit.

Both windows and the plugin must remain open. The editor reports a missing plugin after 30 seconds without plugin activity; long captures send a separate heartbeat. Pending native writes remain labeled as waiting until Figma acknowledges them. Temporary read failures retry automatically. The connection is local, capability scoped, and expires after 30 minutes without activity. Connection credentials are never written into the deck.

Local edits show **Changes waiting to sync** before the next polling cycle. Wait for the native acknowledgement before disconnecting if both versions must contain the latest edit. The last acknowledged document pair is saved in this browser at this local address. One compressed snapshot per document replaces the previous snapshot, with deduplicated media and no connection credentials. If browser storage fails, the live connection continues and the editor explains that recovery is available only for the current session.

After an editor reload or plugin restart, open the same local document, choose **Reconnect Figma**, copy the new code, and connect in the original Figma file. Reloading releases the previous plugin connection automatically. Recovery first reads the previously linked slide IDs, regardless of the plugin's current range or selection. It merges both versions against their last acknowledged state before sending changes. Independent edits survive; conflicting edits pause for a choice. Reconnecting to another file is rejected without consuming the code. The existing local document is retained, including transformed masks; no additional import is required. Changing documents closes the connection before a delayed native response can change the new document. Closing a connection preserves both documents.

Recovery requires at least one successful acknowledgement with this version. Documents without a saved checkpoint, or browsers whose stored data was cleared or damaged, offer the initial connection choices. Importing the current Figma state creates a separate local document and preserves the existing one.

For a supported edit that failed, correct the cause and choose **Retry sync**. After changing the local document, use Deck Studio's retry action: it replaces the rejected command before resuming the plugin. The Figma-side action retries the pending command after a native issue, such as a missing font, is resolved. The editor continues checking for native recovery and resumes when the plugin succeeds. An uncertain write or publication requires **Reconnect Figma** so the native version is read before another write.

Committed edits wake synchronization immediately after a short debounce. Native changes use connected-page events where available; older hosts keep periodic snapshots. Waiting reads can be cancelled without interrupting writes. Unchanged glyphs are reused during unrelated moves; changing their content, style or geometry captures them again. Coordinate fields retain fractional values, and distant slide rows avoid unnecessary absolute-coordinate rounding.

Changes update linked native objects in place. Independent property edits merge; concurrent changes to the same property pause for a choice in Deck Studio. Incoming edits are undoable. Importing from Figma creates a new local document. Unknown native siblings and unselected slides are preserved.

Page order follows the current native slide grid. Duplicating an imported page in Deck Studio makes a separate native copy of its layers, including masks, gradient text and transitions. Editing the copy does not retarget the original. Native copies of connected pages made while the plugin is connected also appear as distinct pages in Deck Studio. Other unlinked native pages remain outside the connection; connect the desired range to include them.

Automatic native page numbers update without adding an Undo entry or clearing Redo. Equivalent text run segmentation also preserves native text paint and automatic leading. A fresh connection reads existing native copies owned by the document even when their saved source points to the original page. If a native source has actually been deleted and no surviving source can recreate the copy, sync stops before replacing its layers; restore that source with Undo in Figma and retry.

For an offline handoff, export **Figma Slides** from Deck Studio and use **Open Deck file** in the plugin. Export **Deck file** from the plugin to import back into Deck Studio. Keep source references for comparison.

Native text retains a validated glyph cache while its content remains editable. Content-only edits preserve native gradient fills and automatic leading; successful synchronization refreshes the cache without adding an Undo step. Native text, basic shapes, image layers, skipped slides and supported transitions transfer. Speaker notes use the native property when exposed. In desktop environments without that property, Deck-authored notes are kept with the slide for Deck round trips and a compatibility notice is shown; copy them into Figma's presenter notes for native presenting. Existing native presenter notes cannot be read or changed by that plugin environment.

Translucent native text keeps its glyph outline and applies the node's opacity separately. Mask opacity can return from zero while preserving native children. Timing-only edits retain the native direction, curve and automatic advance; the Motion panel shows the source's full duration and curve instead of a capped local preset value. Native Smart Animate uses the full transition timeline for incoming and outgoing unmatched objects, including transitions with no matched objects. Ordinary Deck animation timing remains unchanged.

Authored charts and custom shapes use vector assets with independent page identities. Changes refresh the existing native root, retaining its ID and stacking position. Image SVGs preserve their viewBox fitting, and authored page dimensions map to native slide coordinates. Assets and fonts are prepared before changing linked content. Complex masks, blended groups, interactive content and paint backgrounds can become visual layers; internal editing is limited. Moving and proportionally resizing a linked visual preserves its native layers. Nonuniform resizing and replacing masked content stop for review. Font families must be available in both editors. Native outgoing slide direction, duration, curve metadata and delayed advance are retained. Basic native transitions and pausable automatic timing share the editor and HTML player; native previous-page navigation is immediate. Spring motion is approximate. Full native auto layout, object animations, interactive widgets and arbitrary Deck structured tables are not interchangeable. Unsupported outbound objects stop before applying changes. This integration does not claim pixel-exact conversion.

Full-template verification: [14 families / 332 pages](../../docs/figma-slides-compatibility.md). Static comparisons do not establish arbitrary motion or PPTX parity.

For a native-linked slide, the Motion panel uses Figma's **Style**, **Direction**, **Timing**, duration and curve controls. The transition belongs to the current slide and plays toward the next visible slide. **None** removes delayed advance, matching native behavior. New local documents can choose **More options → Use Figma Slides transitions**; the same disclosure retains access to Deck's other presets. Apply to all slides and undo use document transactions.

Live-sync compatibility notes include limitations discovered while importing, as well as native write notices. Native polls, stamps, alignment scales, YouTube, video, embedded previews, tables and text links must not be assumed functional from their captured appearance. See the [full feature and workflow inventory](../../docs/figma-slides-feature-parity.md) for current support, missing behavior and native API boundaries. Full Figma Slides functional equivalence is not currently claimed.

Whole-text links: editable native text with one public web, email or phone URL retains its target through the plugin. In Deck Studio, select the text and use **More text options → Link**; Enter saves, Escape cancels, and an empty value removes the link. Incoming updates preserve a focused draft. Clicking another object commits to the original text. Links activate in the browser presentation and portable HTML with pointer, touch or Enter without advancing the slide. Partial text-range links, native slide/node targets, REST-only imports and links inside visual layers are not included in this support.

Connected updates now index only relevant native page subtrees and reuse the native font catalog (refreshing missing fonts or load failures). Link-only edits reuse native visual captures. On hosts without change events, the same native probe cadence uses a wakeable read so local edits need not wait for a polling sleep. Large-scope performance and full native feature equivalence still require separate acceptance.


Existing native tables: visible, unrotated tables within the local grid limits capture cell text plus a native appearance cache. Supported font family/size/weight/italic, underline/strikethrough, fill/color, position and row/column sizing sync in place. Content-only edits preserve native rich text and links. One unambiguous trailing row or column can be added or removed while retaining the original prefix cells, their IDs and native formatting. Native-reference trailing columns grow/shrink the local table by the actual tail width; ordinary local tables retain their existing sizing behavior. A last-cell draft can join a blank-row append and its inverse. Column structure requires unchanged existing cell content and styles. Missing vertical-alignment APIs retain native inheritance for appended cells; explicit alignment changes still reject before mutation.

Middle or ambiguous row/column edits, native TABLE creation/merging, padding/rules and within-cell range formatting remain unsupported. Deleting a tail containing mixed rich ranges, links, complex/transparent paints or other known formatting that local Undo cannot reconstruct rejects before mutation. New tables and local duplicates use editable FRAME/TEXT/vector cell-layer groups when native table authoring is unavailable; bounded metadata retains their local merge/split, row/column and supported cell-style behavior. The native TABLE toolbar is unavailable for these groups. Fonts and capabilities preflight before writes; native size clamps above 0.1px reject with a sizing message, and mutation failures use the existing native Undo rollback boundary.
